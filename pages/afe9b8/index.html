    electron

    # 介绍

    框架封装的electron功能，将在此模块提供API。

    注：子进程中无法使用所有涉及electron的api

    # 使用方法

    const { 
    getMainWindow,
    setCloseAndQuit,
    getCloseAndQuit,
} = require('ee-core/electron');

    # API列表

    # getMainWindow

    返回主窗口对象。包含BrowserWindow的所有实例api

    # setCloseAndQuit

    设置一个标识，用来控制窗口退出。

    # getCloseAndQuit

    返回 Object 。用来控制窗口退出。
