    # app对象说明

    全局app对象，挂载了许多功能。

    # 推荐

    请升级 ee-core >= v2.1.0 ，使用模块化的api。

    注意： 框架中的 this.app 不等于 electron的app ，开发者注意区分。一般情况下，使用别名来区分：

    const { app: electronApp } = require('electron');

    该对象不再更新，请使用模块化api。
