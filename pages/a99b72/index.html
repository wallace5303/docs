    # 介绍

    electron-egg框架核心功能由 ee-core 和 ee-bin 驱动。目前包含 100+ api，极大的增强了框架能力。

    # 模块列表

    # ee-core

    框架核心功能，提供 api

    # ee-bin

    脚本、命令行工具，负责框架开发、编译、加密、打包等。

    # ee-go

    go 语言支持
