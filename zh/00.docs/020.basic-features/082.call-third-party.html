本页目录

在项目中，通常需要调用（打开）第三方软件，如exe、bash脚本、dll库等；

额外资源目录 ​

bash
./build/extraResources

内部逻辑 ​

  • 生成软件时，将 额外资源目录 一起打进软件安装包
  • 软件安装后，将资源解压到：软件安装位置/resources/extraResources

使用 ​

javascript
# 打包前后资源路径不同

const { getExtraResourcesDir } = require('ee-core/ps');
# getExtraResourcesDir() 会自动判断当前是打包前，还是打包后
let softwarePath = '';
softwarePath = path.join(getExtraResourcesDir(), softName);

# demo已经在项目中，请查看
# 方法一
/**
 * 调用其它程序
 */
openSoftware (softName) {
  .......
}

# 方法二
框架提供了 cross 模块，提供跨平台的 api 来调用第三方程序

demo中powershell.exe 软件位置

bash
